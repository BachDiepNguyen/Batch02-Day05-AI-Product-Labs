# Failure test log

Ban chi tiet nam trong `prompt-tests-or-failure-log.md`.

File nay duoc them de khop voi checklist nop bai co ten `failure-test-log.md`.

## Failure paths covered

- Low-confidence: user khong nho kenh mua ve / thieu dieu kien ve.
- Safe boundary: user muon tra cuu booking bang ten va so dien thoai.
- Deadline failure: chuyen bay khoi hanh sau 2 tieng, khong con mua hanh ly tra truoc online.
- Constraint failure: vali 25kg va 160cm vuot chuan 23kg/158cm.
- Entitlement risk: user khong biet ve da co hanh ly mien cuoc chua, co the mua thua add-on.
- Add-on validity: da mua hanh ly tra truoc nhung doi ngay/chuyen bay.
- Special baggage: tui the thao qua kho can route hanh ly dac biet.
